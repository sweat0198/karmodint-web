Try Live Configurator

1. Multi-Level Categories

Categories can have subcategories (e.g. Cabins → Standard Offices). Products can belong to multiple categories for maximum customer discoverability.

2. Mandatory Metric Sizes

Every product requires at least 1 size option (Length × Width in meters) with an explicit price. The frontend automatically calculates imperial feet/sq ft.

3. Central Customizations

Electricity packages, Heaters, WCs, and Kitchens are managed once in a central library. Products pick which options apply to them.

4. Smart Pricing & Custom POA

Supports instant pricing (+£350), included features (£0), and custom quotes (POA) with customer note prompts for special electrical layouts.

Detailed Schema Field Specifications
📁 Category Document (`category.ts`) Taxonomy & Navigation
Field Name Type Business Purpose Rules / Validation
name String Category display title (e.g. "Portable Cabins", "Kiosks") Required
slug Slug URL address path (e.g. /categories/portable-cabins) Required (auto-generated from name)
parent Reference (Category) Creates subcategories (e.g. "Cabins" ➔ "Gatehouses") Optional (empty = Top Level category)
description Text Introductory text displayed at the top of category page Optional
image Image + Alt Text Category card image in header navigation and grid listings Hotspot enabled + Alt text required
displayOrder Number Sort order in navigation menu and category lists (1, 2, 3...) Default 10 (lower numbers show first)
seo Object Custom Google title & description for category pages Optional override
📦 Product Document (`product.ts`) Core Catalog Entity
Field Name Type Business Purpose Rules / Validation
name String Product display title on website and quote emails Required
slug Slug SEO-friendly URL path (e.g. /products/portable-office-cabin-6m) Auto-generated from name
categories Array of References Assigns product to one or more primary and sub-categories Required (min 1)
sizes Array of Size Objects Mandatory cabin sizes with Length(m), Width(m), Height(m), Price (£) Required (min 1 size)
customizationGroups Array of References Links Electricity, Heater, WC, Kitchen options to this product Optional
images Array of Images High-resolution product gallery with required alt text for SEO Required (min 1)
specifications Array of Key-Values Technical table (Insulation, Steel Frame, Glazing, Fire rating) Optional
seo Object Google meta title, meta description, and social share image Optional override
