# Requesting Code Review

Read and follow the full skill instructions:

// turbo

1. Read the skill file at `~/.agents/skills/superpowers/requesting-code-review/SKILL.md` using `view_file`

2. Get git SHAs for the review range (base and head commits).

3. Prepare a review request with:
   - What was implemented
   - Plan or requirements it should satisfy
   - Base and head SHAs
   - Brief description

4. Act on feedback: Fix Critical issues immediately, Important issues before proceeding, note Minor for later.
