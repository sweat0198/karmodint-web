# Brainstorming Ideas Into Designs

Read and follow the full skill instructions:

// turbo

1. Read the skill file at `~/.agents/skills/superpowers/brainstorming/SKILL.md` using `view_file`

2. Announce: "I'm using the brainstorming skill to explore this idea."

3. Follow the checklist in order:
   - **Explore project context** — check files, docs, recent commits
   - **Ask clarifying questions** — one at a time, understand purpose/constraints/success criteria
   - **Propose 2-3 approaches** — with trade-offs and your recommendation
   - **Present design** — in sections scaled to complexity, get user approval after each
   - **Write design doc** — save to `docs/plans/YYYY-MM-DD-<topic>-design.md`
   - **Transition to implementation** — invoke `/writing-plans` workflow

4. **HARD GATE:** Do NOT write any code until the design is approved by the user.
