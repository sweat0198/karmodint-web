# Receiving Code Review

Read and follow the full skill instructions:

// turbo

1. Read the skill file at `~/.agents/skills/superpowers/receiving-code-review/SKILL.md` using `view_file`

2. Follow the response pattern:
   - **READ:** Complete feedback without reacting
   - **UNDERSTAND:** Restate requirement in own words (or ask)
   - **VERIFY:** Check against codebase reality
   - **EVALUATE:** Technically sound for THIS codebase?
   - **RESPOND:** Technical acknowledgment or reasoned pushback
   - **IMPLEMENT:** One item at a time, test each

3. If any item is unclear, STOP and ask for clarification before implementing anything.

4. Push back when: suggestion breaks existing functionality, violates YAGNI, or reviewer lacks full context.
