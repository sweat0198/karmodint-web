# About Concept Label Removal Design

## Goal

Remove visible `Concept visualisation` overlay labels from all generated imagery on the About page.

## Scope

- Remove hero `figcaption` overlay.
- Remove Vision and Mission `figcaption` overlays.
- Preserve generated images, responsive formats, loading behaviour, framing, and surrounding layout.
- Preserve accurate concept-based alt text for assistive technology.
- Update component tests to assert captions are absent.
